### 前言

我们从降生到这个世界起，就一直生活在颜色的包围里，也一直享受着被颜色围绕的快乐——就像在颜色的海洋中游泳一样。对颜色的认识，我们几乎都是在无意识中一点点建立起来的。能看见『颜色』，对我们而言是一件理所当然、没有任何不可思议之处的生活常识。

在平常的生活和工作中，我们能从颜色里得到各种各样的信息，并依据这些信息去思考、去行动。颜色对人类生活的影响之大，无论在物质层面还是精神层面都不容小觑。即便如此，中小学阶段关于颜色的知识，仍以制图、美术这类艺术层面的内容为主；少数能从理科侧面学到的，也不过是牛顿的三棱镜分光实验之类。大学同样如此，除了特定学科，能从科学角度系统学习『颜色』这一日常概念的机会少之又少。所以这里，我们就针对「颜色是什么」这个设问，尽可能简单易懂地从科学层面讲一讲。

首先，我相信很多人都认为，物体的颜色是作为固有属性被「染」上去的。比如红透的草莓，就是染上了植物性的真红色；早春的嫩叶，就是被亮绿色染上的。这似乎被当成事实而深信不疑——但真的是这样吗？

详细的说明稍后展开，这里先把结论放在前面：『颜色』其实要先有『光』与『视觉（感觉）』存在，才得以成立。然而，认为『光』与『颜色』完全是两码事的人，仍然不在少数。对『颜色』来说，它绝对无法脱离『光』，两者绝不是互不相关的东西。

### 机器视觉与『颜色』

『颜色』之所以能够成立，『光』与『视觉（动物的眼与脑）』是必不可少的条件。人眼可以把光分割成几个不同的波长区域分别感知，大脑则依据来自眼睛的这几个波长域的刺激之间的关系做出判断，从而形成对颜色的认识。人眼与大脑具备了人类特有的特性，这个特性构成了「人类的色觉」。

人类的色觉，是作为地球上的动物在进化过程中获得的属性。物种不同，获得的色觉特性也不同，人类以外的动物，生活在与我们截然不同的「颜色世界」里。实际上，即便同为人类，别人眼中的颜色与你看到的颜色究竟是否一致，也是很难确定的。至于人类以外的物种究竟看到一个什么颜色的世界，那就只有神知道了。不过，我们仍然可以通过研究各种动物的视觉细胞与视神经，在今天某种程度上推测出它们的视觉特性。

按照上面的说法，在机器视觉这个方向上，除去一些特殊场合，狭义的『颜色』并不适用——这未必是坏事。但即便是机器视觉，也经常需要对『颜色』做出判断；不仅如此，还可以把『光』拆分为不同的频谱带，求取各谱带之间的强度比，借此去解释广义上的『颜色』。无论哪一种，由于机器视觉触及底层的机会很多，理解『颜色』的本质，对从事机器视觉的工程师们都会有所帮助。

> **笔者注**：在机器视觉领域里，充当「眼球」的是 Camera。它「看」见东西的链路是这样的。
>
> Camera 的 Sensor 是一片紧密排列的感光素子阵列，每个素子负责测量一段时间内落在它上面的光强度，这段时间就是曝光时间。可以想象成拿杯子接水：泉水不停地流，你把杯子放在下面接一会儿，杯里的水量就是这个素子测到的光强。整个阵列接完一轮，得到的强度分布就是一张图像。
>
> 但这样拿到的只有强度，没有颜色——它是一颗黑白 Sensor。要拿到颜色，就得在素子前面盖一层 Color Filter，让每个素子只接收一部分波长的光；代价是每个像素只剩下一个通道，后面还得用 Demosaic 算法把缺失的通道补回来。
>
> 这还远远没完。Sensor 的光谱响应和人眼并不一样，同一个场景，它「看」到的和你看到的是两回事。相机的成像系统（通称 ISP，Image Signal Processor），还包含了一长串色彩处理链路——白平衡、色彩校正矩阵（CCM）、色调映射——本质上都在弥合这个差距。往大了说，色彩科学在计算摄影与计算成像领域内，主要面对的正是这一类问题：Sensor 与人眼的差异、不同光源下的色彩还原，以及显示设备的色域与色彩管理等等。
{: .prompt-info }

### 光乃颜色之源

我们之所以能看到东西（比如草莓），是因为有照射物体的光（可见光）存在，光在物体（草莓）表面产生反射，这束反射光最后射入人眼。

因此，照明光一旦消失，视界也就变成漆黑一片，形状就不用说了，『颜色』也看不见了。也就是说：

> 照射光源乃『颜色』之源，是『颜色』存在的前提条件。
{: .prompt-tip }

![有光与无光下的草莓，以及光源、物体与眼睛的关系](/assets/resource/What-is-Color/light-is-mother-of-color.png){: width="720" }
_光源消失，形状与颜色一并消失_

### 颜色的感知，得益于「眼」与「脑」

虽说「光乃颜色之源」，但只要光存在，『颜色』就存在吗？答案是否定的。

在光学史上留下伟大足迹的牛顿，早在其著作《光学》（*Opticks*）中就写下过这样一句：

> For the Rays to speak properly are not coloured. In them there is nothing else than a certain Power and Disposition to stir up a Sensation of this or that Colour.
>
> ——严格来说，光线本身并没有颜色。它们所具有的，只不过是一种能够激起「这种或那种颜色」之感觉的能力与倾向罢了。

从光源发出的光照射到物体上并产生反射，这束反射光再射入人眼——直到这个阶段为止，它都还仅仅是单纯的物理能量。能够感知这份光能的，是分布在视网膜上、被称为视觉细胞的东西。视觉细胞受到射入光线的刺激后，把刺激的大小转换为信号送往大脑，大脑再根据这些信号去辨别颜色（以及形状）。

视觉细胞大致分为两类：一类是在较强光照环境下工作的**视锥细胞**，另一类是在较弱光照环境下工作的**视杆细胞**。我们之所以能感受到『颜色』，靠的正是视网膜上视锥细胞的作用。

视锥细胞又可以按波长感受特性的不同再细分为三类：对可见光短波部分较敏感的 $S$ 视锥细胞，对中波部分较敏感的 $M$ 视锥细胞，以及对长波部分较敏感的 $L$ 视锥细胞。

> **注**：$S$ / $M$ / $L$ 分别取自 Short / Medium / Long，其光谱敏感度峰值大致在 420 nm、534 nm、564 nm 附近。需要注意的是，$L$ 与 $M$ 的峰值只差 30 nm 左右，二者的响应曲线高度重叠——所以把 $S/M/L$ 直接对应成「蓝 / 绿 / 红」三种颜色是一种过度简化的说法，它们本身并不「是」某种颜色。
{: .prompt-info }

对于射入眼睛的光，三种视锥细胞会依据各自的感光特性产生强弱不同的刺激。这三路代表不同刺激强度的信号经由视神经传导至大脑，大脑再通过这三种刺激信号之间的**强弱比**，将其辨识为『颜色』。也就是说，『颜色』最终是在大脑完成认识之后才成立的，在此之前的所有环节里，都还不存在『颜色』这一概念。

![入射光经三种视锥细胞转成三路刺激强度，视觉系统再由三者之比得出颜色](/assets/resource/What-is-Color/eye-brain-lms.png){: width="760" }
_从光能到『颜色』：真正被读取的是 $L : M : S$ 三者之比_

> **注**：严格讲，把三路锥体响应加工成颜色信息的过程并非全部发生在大脑。早在视网膜内部，水平细胞与双极细胞就已经把 $L/M/S$ 的响应组合成了「红—绿」「蓝—黄」「明—暗」三组拮抗信号（opponent process），再经神经节细胞送出。不过这并不影响本文的结论——无论这份加工发生在眼里还是脑里，它都是**感觉系统**的加工，而不是光本身或物体本身的属性。
{: .prompt-info }

### 「光源色」与「物体色」

上面主要阐述了：『光』与『视觉』是『颜色』存在的必要条件。

虽然我们都笼统地称之为『颜色』，但把它做一个大致的分类，可以分为光源自身散发出来的颜色（称为**光源色**），以及受光源照射的物体所呈现出来的颜色（称为**物体色**）。不仅如此，物体色还可以再分为两类：一类是在物体表面反射后所呈现的颜色（称为**表面色**，或反射物体色），另一类是透过半透明物体后的光所形成的颜色（称为**透过色**，或透过物体色）。

光源色，是光源的光直接射入人眼、刺激视锥细胞而被认识到的颜色。

物体色，则是光源的光先照射到物体上，受到该物体特有的光谱反射（或透射）特性的调制之后，再射入人眼、刺激视锥细胞而被认识到的颜色。也就是说，在我们日常看到的颜色之中，仅靠『光』与『视觉』两个要素就能成立的，是光源色（下图 [a]）。

![光源色与物体色的成立要素韦恩图](/assets/resource/What-is-Color/color-elements-venn.png){: width="600" }
_[a] 光源色的成立要素；[b] 物体色的成立要素_

> **笔者注**：前面提到的、盖在 Camera Sensor 之前的那层 Color Filter，做的正是这件事——利用滤色片的滤波特性，让每个素子只收下一段波长的光，再从这些「透过色」的强度反推出原本的色彩。这些滤色片排成的阵列一般称作 **CFA（Color Filter Array）**，其中最常见的排布方式就是 **Bayer 阵列**：以 2 × 2 为最小单元，红、蓝各占一个，绿占两个。
>
> 绿色之所以翻倍，是因为人眼对中波段最敏感——多采一份绿，换来的是亮度信息的精度。而整个 CFA 方案的共同代价是分辨率：每个像素位置只拿到三个通道中的一个，缺的那两个得靠 Demosaic 算法从邻居那里推算回来。
>

我们经常能察觉到，同一个东西在不同光源下颜色会有些许不同。烛光偏红，公园夜间照明常用的水银灯是青白色的，隧道照明常用的钠灯则是橙色的。这是因为不同光源在各个波段上的能量强度分布（**光谱分布**）不同，人眼视锥细胞受到的刺激也就不同，最终看到的颜色自然不同。

而我们平常实际看到的颜色，基本上都是物体色。相同照明光下不同物体呈现出的颜色不一样，说明物体自身所具有的特性，是决定最终『颜色』的一个重要要素。正如前面韦恩图中的 [b] 所示，『光』『视觉』『物体』这三个要素相重叠的区域，才是最终呈现出来的物体色。

所以，**『光源』、『视觉（眼与脑）』、『物体』被称为物体色的三要素**。

### 草莓与柠檬的颜色为何不一样？

对于物体色，举个例子：同样是在阳光下，我们看到草莓和柠檬的颜色明显不同。

当光源射出的光线照射到物体上并发生反射时，物体表面会反射掉某些波段的光，同时吸收掉另一些波段的光。正因为这种特性（**光谱反射率特性**）与物体的种类息息相关，才造成了在同一照明光下，不同物体看起来是不同颜色的。

> **先交代一下本节的两位主角**：为了让下面的曲线和颜色都有据可查，我翻了几个开源的光谱反射率数据库，但都没有草莓和柠檬的实测数据。所以从这里起，**红色一方由越橘的红色浆果（puolukka）出演，黄色一方由蒲公英的黄花（voikukka）出演**——它们的光谱行为与草莓、柠檬是同一类，论证完全通用。下文凡是提到它们的地方都会用括号标出替换关系，比如「越橘（代草莓）」，方便你随时把它们读回原来的水果。

把越橘（代草莓）与蒲公英（代柠檬）的光谱反射特性放在一起比较，大体上可以看到一个共同点：两者都在长波光（看起来偏红的光）上有强烈的反射，而短波光（看起来发蓝的光）则基本被吸收。但在中波段（看起来偏绿的光）上，两者差异很大——越橘的中波段光基本被吸收了，蒲公英却对中波段的光有较强的反射。这正是红（草莓）与黄（柠檬）颜色差异产生的原因。

对于越橘（代草莓）来说，长波段的光大部分被反射，而中波段与短波段的光被吸收。因此在我们周围常见的白色光源（太阳光、日光灯等）下，射入眼睛的光长波成分较强，$L$ 视锥细胞受到强刺激，$M$ 与 $S$ 视锥细胞则基本不受刺激。结果，视觉系统把这个组合解读成了草莓那样的红色。

同样地，对于蒲公英（代柠檬）来说，不仅长波段的光被反射，中波段也有较强的反射，短波段则与越橘一致，基本被吸收。因此对它而言，$L$ 视锥细胞同样受到强刺激，但与越橘不同的是，$M$ 视锥细胞也会受到相当程度的刺激，而 $S$ 视锥细胞基本不受刺激。结果，$L$ 与 $M$ 同时被强烈刺激、$S$ 几乎没有响应——视觉系统把这个组合解读成了柠檬那样的黄色。

归根到底，物体的颜色是由三者共同决定的：光源的特性（光谱分布）、物体的特性（光谱反射率或光谱透射率），以及眼睛（视觉细胞）的特性。

### 物体自身并不带有颜色

在物体色的三要素中，任一要素发生变化，都会引起『颜色』的变化。

『光源』与『视觉』是『颜色』存在的前提条件，而『物体』在这中间扮演的角色，其实只是一个**波长选择性的滤波器**：它把光源送来的能量按波长做了一次取舍，反射（或透射）掉一部分、吸收掉另一部分，交到眼睛手上的，仍然是一束改变了光谱分布的光，是纯粹的物理能量。物体并没有往这束光里「添加」任何叫做颜色的东西。『颜色』要等到这束光射入眼睛、刺激三种视锥细胞、并由视觉系统解读出刺激强度比之后才会产生——所以在射入眼睛之前的所有阶段，『颜色』并不存在。物体所拥有的，从头到尾都只是「光谱反射率」这样一个物理属性，而不是『颜色』。

话讲到这个份上，可能仍然有人没能把「物体自身带有颜色」这个先入为主的观念彻底拔除。

当然，上述例子中使用的照明光源都是类似太阳光那样、在整个可见光范围内都有能量分布的『白色光』。那么，当照明光不再是白光，而换成单色光的时候，会发生什么呢？

这个问题不必靠想象，也不必去搭一套灯光拍照——**它可以直接算出来**。前面那两条曲线是实测的光谱反射率，LED 的光谱也有实测数据，两者一乘再送进视觉系统的模型，颜色就出来了。所以下面每一个色块都是算出来的结果，而不是画上去的效果。

> **图中数据来源**：LED 光谱取自 CIE 实测光源 `3-LED-4 (455/547/623)`——它本身是一颗三芯片白光 LED，按波段拆开就得到蓝、绿、红三个单色分量。反射率乘上它之后，用 CIE 1931 标准观察者积分成 $XYZ$ 再转 sRGB，就是图中的色块。
>
> 「相对亮度」以同一光源下的理想白面为 100%。另外要提醒一句：单色光的饱和度超出了 sRGB 色域，屏幕上显示的颜色已被裁切，实际比图上更纯。
{: .prompt-info }

#### 用红色 LED 照明

![红色 LED 的光谱与两种物体的反射率，以及算出的呈色](/assets/resource/What-is-Color/red-led-illumination.png){: width="820" }
_红色 LED 只在长波段有能量，两者都把它反射了出来，于是呈现同一个红_

不只是越橘（代草莓），连蒲公英（代柠檬）看起来也呈现出饱和度相当高的红色——算出来两者都是同一个 `#FF0000`。原因在于，两者都在长波段有强烈的反射，大部分长波长的光都被反射进了人眼。而红色 LED 本身并不含有短波与中波成分，因此这两段无论反射率高低，都没有对应的反射光。两者的差别只剩下亮度（越橘 55%、蒲公英 98%），色相上已经分不出来了。

#### 用蓝色 LED 照明

![蓝色 LED 的光谱与两种物体的反射率，以及算出的呈色](/assets/resource/What-is-Color/blue-led-illumination.png){: width="820" }
_蓝色 LED 的能量正好落在两者都吸收的波段上，于是两者都很暗_

越橘（代草莓）和蒲公英（代柠檬）看起来都非常暗（一种略带蓝紫的黑），亮度只剩 12% 与 7%。原因在于，两者在短波段的反射率都比较低，光基本被物体吸收，只有极少的部分被反射出来。而蓝色 LED 只含有短波长的光，所以中波段与长波段的反射率高低在这里完全不起作用——那两段再怎么擅长反射，也没有光可反射。

#### 用绿色 LED 照明

![绿色 LED 的光谱与两种物体的反射率，以及算出的呈色](/assets/resource/What-is-Color/green-led-illumination.png){: width="820" }
_绿色 LED 的能量落在两者反射率差异最大的波段上，亮度拉开了约 7.5 倍_

蒲公英（代柠檬）呈现出明亮的绿色（90%），越橘（代草莓）则显得非常暗淡，只是一团略带绿意的深色（12%）——两者相差约 7.5 倍。蒲公英在中波段的反射率非常高，大部分中波长的光被反射入眼；与之相对，越橘的中波长光基本被吸收，几乎没有反射。三种 LED 里，只有绿色这一支把两者区分开了。

![白光与红、绿、蓝三种 LED 照明下，两种物体呈色的对照表](/assets/resource/What-is-Color/rgb-led-comparison.png){: width="640" }
_四种光源 × 两个物体，共八个色块全部由光谱算出_

也就是说，在红色 LED 与蓝色 LED 照明下，越橘与蒲公英都难以区分开来（前者同为一个红，后者同为一团暗色）；而在仅含中波长能量的绿色 LED 照明下，由于反射特性的差异，两者才拉开了明显的差别。

上面的例子为了讲清楚原理，刻意用了比较极端的照明光源。但回到日常经验里也是一样的：在商场里看中买回来的衣服，回到家里、或者走到室外再看，颜色总与在商场时有些出入，有过这种体验的人想必不在少数。同样的衣服、同样的观察者，在商场里看着高端大方，回到家却觉得颜色和质感都变了样。这是因为商场在试衣间和展位上用足了「心机」灯光：超高的显色指数、立体饱满的光影、精心搭配的色温。这就是色彩科学的另一个用武之地——商业照明设计。

> **笔者注**：这个现象非常普遍。在色彩科学里对应两个概念：一是**同色异谱（metamerism）**，即两个光谱分布不同的色块在某一光源下看起来同色、换个光源就露馅；二是光源的**显色性（CRI / $R_a$）**，描述光源还原物体本来颜色的能力。对做相机的人来说，这两件事正是自动白平衡与色彩校正矩阵（CCM）必须面对的麻烦——传感器的 $R/G/B$ 响应和人眼的 $L/M/S$ 并不相同，换一个光源，同一个物体在 RAW 里的数值就是另一回事了。
{: .prompt-info }

到这里，大家应该可以充分理解「物体自身绝对不带有颜色」的原因了吧。

### 小结

- 『颜色』不是光的属性，也不是物体的属性，而是**光、物体与视觉系统三者共同作用后，在感觉层面产生的结果**。
- 光源决定了送进来的能量在各波长上如何分布；物体只是按波长对这份能量做了一次取舍；真正把物理量变成『颜色』的，是视觉系统对 $L/M/S$ 三路响应之比的解读。
- 三者中任何一个发生变化，『颜色』就会变化——同色异谱之所以会在换了光源之后露馅，正是这个道理；这也是相机做白平衡与色彩还原时始终绕不开的前提。
