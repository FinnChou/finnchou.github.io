三原色能表示的颜色：色域与线性

「红绿蓝三原色可以混出所有颜色」的说法并不正确。本篇从蓝色 LED 获诺贝尔奖的报道说起，讲解三原色加法混色所能表示的范围（色域）为何是三角形，以及色度图上加法混色的线性。

前言

2014 年 10 月 7 日，2014 年度诺贝尔物理学奖公布：名城大学终身教授赤崎勇、名古屋大学教授天野浩与加利福尼亚大学教授中村修二三人，因研发蓝色发光二极管（LED）并使之实用化而获奖。红色与黄绿色的 LED 在 1960 年代就已经存在，蓝色 LED 的技术门槛却相当高，曾被认为在 20 世纪内难以实用化。三位获奖者从材料开发到量产技术打通了整条道路，为今天的 LED 时代奠定了基础。

有了位于可见光短波段的蓝色 LED，能量效率高、寿命长的 LED 白色光源才成为可能，进而替代了 19 世纪末以来的白炽灯和后来广泛使用的荧光灯，在节能上贡献巨大。

在传递这则喜讯的报道里，有一处说法值得推敲。不少媒体在解释「蓝色 LED 的实现，与已有的红色、绿色 LED 一起集齐了三原色」这句话时，都会附上一句说明：用红、绿、蓝三原色可以做出「所有的颜色」。严格地说，这句话并不正确：存在无论怎样混合三原色也无法得到的颜色。

三原色光的混色范围（色域）

红 $[R]$、绿 $[G]$、蓝 $[B]$ 三原色的光经加法混色所能得到的颜色范围，称为色域（色彩再现域）。在 $xy$ 色度图上，它就是以三原色的色度点 $R$、$G$、$B$ 为顶点的三角形 $\triangle RGB$ 的内部（含边界）。$\triangle RGB$ 之外的颜色过于鲜艳，无法由三原色混合得到。其中的道理，可以对照《颜色的客观表达（三）：从 RGB 到 XYZ》里对等色实验的说明来理解。

三原色的加法混色只能做出 $\triangle RGB$ 内部的颜色。实线以 sRGB（BT.709）的三原色为例，虚线以 CIE RGB 表色系的三种单色光原刺激为例

$xy$ 色度图最外围的曲线（单色光轨迹，即光谱轨迹）是向外凸的。因此无论怎样选择 $[R]$、$[G]$、$[B]$ 的组合，都必然留下 $\triangle RGB$ 覆盖不到的区域。

LED 的光并不是纯粹的单色光，一般是半值宽度在几十纳米以内的窄带光。所以在 $xy$ 色度图上，单色 LED 的色度点必定落在光谱轨迹稍靠内的位置。即便把三原色都取成光谱轨迹上的单色光（例如 RGB 表色系等色实验用的三种原刺激），也只是使 $\triangle RGB$ 有所扩大，三角形之外仍有一部分颜色无法覆盖。

因此，前面那句媒体的说法，严格的表述应该是：用红、绿、蓝三原色可以做出「几乎所有的颜色」。彩虹就是一个例子：彩虹的颜色是阳光经水滴折射、色散得到的单色光（原连载第 19 回专门讲过彩虹，本站未收录），其色度点位于光谱轨迹上，也就是在 $\triangle RGB$ 之外。电视画面上的彩虹、书籍印刷的彩虹，都没有准确地再现彩虹的颜色，严格地说，只是把「接近彩虹的颜色」呈现得不显突兀而已。同样，本系列文章里的 $xy$ 色度图，其外围（光谱轨迹与纯紫轨迹）附近的颜色，也并没有真实再现实际的颜色。

色域为什么是三角形

那么，三原色 $[R]$、$[G]$、$[B]$ 的加法混色结果，为什么总落在 $xy$ 色度图的 $\triangle RGB$ 之内？这需要从数学上加以说明。$xy$ 色度图在数学上是一个线性空间，这一「线性」的性质，正是「两个颜色的混色结果，其色度点落在连接这两个颜色的色度点的直线上」的直接原因。

三原色 $[R]$、$[G]$、$[B]$ 的混色，可以分成两步来看：先把 $[R]$ 与 $[G]$ 混合，再把结果与 $[B]$ 混合。第一步的结果落在线段 $RG$ 上，第二步的结果落在该点与 $B$ 的连线上。所以三种颜色的混色结果，其色度点必然落在三个色度点围成的三角形 $\triangle RGB$ 之内。

什么是「线性」

数学上所说的「线性」，指的是可以用一次式来表示的关系。最简单的一次式是 $y = Ax$（$A$ 为常数）：$x$ 与 $y$ 成正比，在 $xy$ 平面上是一条过原点、斜率为 $A$ 的直线。变量 $x$ 的变化量 $\Delta x$ 与函数值 $y$ 的变化量 $\Delta y$ 之比 $\Delta y / \Delta x = A$ 为定值，所以图像是直线，这一性质就称为「线性」。

对 $y = Ax$ 做 $y’ = By + C = ABx + C$ 这样的变换（横轴 $x$ 不变），纵轴变成了 $y’$，斜率由 $A$ 变为 $AB$，截距由 $0$（过原点）变为 $C$。也就是说，坐标由 $xy$ 变换到了 $xy’$，但「图像是直线」这一性质被保留了下来。

「线性」：用一次式变换，直线仍是直线（模式图）

与之相对，若做 $y’’ = x \cdot y = x \cdot Ax = Ax^2$ 这样的变换，$xy’’$ 坐标下的图像变成了二次曲线（抛物线），原坐标系 $xy$ 下「图像是直线」的性质没有保留下来。

一般地，用一次式（变量的次数为 1 的式子）做变换，直线仍变换为直线，这样的变换称为线性变换；变换式不是一次式时，直线会变成曲线（线性没有保留），这样的变换称为非线性变换。

加法混色与色度图的线性

下面说明上述线性与混色之间的关系。

作为 XYZ 表色系的原理基础的 RGB 表色系，其三刺激值 $(R, G, B)$ 定义为

\[\left\{ \begin{array}{l} R = k \displaystyle\int_{380}^{780} P(\lambda)\, \rho(\lambda)\, \overline{r}(\lambda)\, d\lambda \\[6pt] G = k \displaystyle\int_{380}^{780} P(\lambda)\, \rho(\lambda)\, \overline{g}(\lambda)\, d\lambda \\[6pt] B = k \displaystyle\int_{380}^{780} P(\lambda)\, \rho(\lambda)\, \overline{b}(\lambda)\, d\lambda \end{array} \right.\]

其中 $P(\lambda)$ 为照明光的光谱分布，$\rho(\lambda)$ 为物体的光谱反射率（光源色时取 $\rho(\lambda) = 1$），$\overline{r}(\lambda)$、$\overline{g}(\lambda)$、$\overline{b}(\lambda)$ 为 RGB 表色系的等色函数，$k$ 为常数。由定义式可见，三刺激值表示的是射入眼睛的光给视觉带来的刺激强度（心理物理量），$R$、$G$、$B$ 各自与射入眼睛的「光的强度」成正比。

在 RGB 表色系中考虑一个三刺激值为 $R$、$G$、$B$ 的颜色 $[F]$。以三个刺激值 $R$、$G$、$B$ 为三根相互正交的坐标轴，则颜色 $[F]$ 可以解释为一个向量 $\mathbf{F}(R, G, B)$。

另一方面，RGB 表色系的色度坐标 $(r, g, b)$ 定义为各刺激值占刺激值总量的比：

\[r = \frac{R}{R + G + B}, \quad g = \frac{G}{R + G + B}, \quad b = \frac{B}{R + G + B}\]

于是 $r + g + b = 1$ 成立，向量 $\mathbf{F}(R, G, B)$ 与平面 $R + G + B = 1$ 的交点，就可以解释为色度坐标 $(r, g, b)$。把这个色度坐标也写成向量的形式 $\mathbf{f}(r, g, b)$。

现在考虑两个颜色 $[F_1]$ 与 $[F_2]$ 的混色，设结果为 $[F_M]$。

两色混合：刺激值相加就是向量相加，色度点落在 $\mathbf{f}_1$、$\mathbf{f}_2$ 的连线上（模式图）

如上图，把两个颜色写成 $\mathbf{F}_1(R_1, G_1, B_1)$ 与 $\mathbf{F}_2(R_2, G_2, B_2)$，混色结果记为 $\mathbf{F}_M(R_M, G_M, B_M)$。混色结果的各刺激值为 $R_M = R_1 + R_2$、$G_M = G_1 + G_2$、$B_M = B_1 + B_2$，也就是说，混色结果可以用向量加法表示：

\[\mathbf{F}_1(R_1, G_1, B_1) + \mathbf{F}_2(R_2, G_2, B_2) = \mathbf{F}_M(R_1 + R_2,\ G_1 + G_2,\ B_1 + B_2)\]

和向量 $\mathbf{F}_M$ 位于 $\mathbf{F}_1$ 与 $\mathbf{F}_2$ 所确定的平面内，是以 $\mathbf{F}_1$、$\mathbf{F}_2$ 为邻边的平行四边形的对角线。因此，包含 $\mathbf{F}_1$、$\mathbf{F}_2$、$\mathbf{F}_M$ 的平面（平行四边形所在的平面）与平面 $R + G + B = 1$ 的交集是两个平面的交线，即一条直线。$\mathbf{F}_1$、$\mathbf{F}_2$、$\mathbf{F}_M$ 与平面 $R + G + B = 1$ 的交点，即色度坐标向量 $\mathbf{f}_1(r_1, g_1, b_1)$、$\mathbf{f}_2(r_2, g_2, b_2)$、$\mathbf{f}_M(r_M, g_M, b_M)$，也都在这条直线上。

这就是说，两个颜色 $[F_1]$ 与 $[F_2]$ 的混色结果 $[F_M]$ 的色度点 $\mathbf{f}_M$，落在 $rgb$ 色度图上连接这两个颜色的色度点 $\mathbf{f}_1$ 与 $\mathbf{f}_2$ 的直线上。

进一步，混色结果的色度点 $\mathbf{f}_M$ 是线段 $\mathbf{f}_1 \mathbf{f}_2$ 的内分点，内分比由 $\mathbf{F}_1$ 与 $\mathbf{F}_2$ 各自的刺激值总量 $R + G + B$ 决定：$\mathbf{f}_M = \dfrac{S_1 \mathbf{f}_1 + S_2 \mathbf{f}_2}{S_1 + S_2}$，其中 $S_i = R_i + G_i + B_i$，$\mathbf{f}_M$ 偏向总量较大的一方。把 $rgb$ 色度图投影到 $rg$ 平面得到 $rg$ 色度图，这一直线关系（线性）仍然成立。

对 RGB 表色系的三刺激值 $R$、$G$、$B$ 做如下变换，得到的就是 XYZ 表色系的三刺激值 $X$、$Y$、$Z$：

\[\left\{ \begin{array}{l} X = 2.7689\,R + 1.7517\,G + 1.1302\,B \\ Y = 1.0000\,R + 4.5907\,G + 0.0601\,B \\ Z = 0.0000\,R + 0.0565\,G + 5.5943\,B \end{array} \right.\]

这个坐标变换是一次变换式，「线性」得以保留：RGB 表色系的 $rg$ 色度图上的直线，在 $xy$ 色度图上仍然是直线。这就是三原色的混色结果总落在 $\triangle RGB$ 之内的原因，也是 XYZ 表色系与加法混色高度契合的原因。
