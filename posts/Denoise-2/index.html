Image Denoise : 非线性滤波器

非线性滤波器通过排序逼近 root 信号，去除椒盐噪声的同时不会明显模糊图像。本篇介绍中值（中央值）、自适应中值、最大值与最小值、中点及修正的阿尔法均值滤波器，附 Matlab 代码。

非线性处理与线性处理的区别

上一篇博文所讨论的均值滤波器，例如算术均值滤波器与几何均值滤波器，其思路都是剔除某些不需要的频率成分，或者选择需要的频率成分，从而达到去噪的目的。这一类滤波器被称为线性滤波器。

除此之外，还有一类被称为非线性滤波器的处理方法，其代表就是中央值滤波器。所谓中央值滤波器，是将一定范围内的数据（对于图像而言，就是像素的灰度值）进行排序，选择其中的中央值作为滤波器的输出。

与线性滤波器不同，中央值滤波器的目的并不在于频率成分的选择，而是求取 root 信号。关于 root 信号的定义，[文献1]中是这样给出的1。

定义：对于任意信号，使用中央值滤波器进行有限次处理，直到所得到的信号不变为止。中央值滤波器处理前后，如果这个信号列没有任何变化，那么将这个信号列称为这个滤波器的 root 信号。

对于中央值滤波器而言，可以完美地去除被椒盐噪声污染的 root 信号。关于 root 信号，有如下的性质，其证明与详细说明请参考[文献2]2与[文献3]3。

定理1：如果信号列 $\lbrace x(i) \rbrace$ 是单调递增或单调递减的，那么对于任何尺寸的中央值滤波器，这个信号列都是 root 信号。

定理2：如果信号列 $\lbrace x(i) \rbrace$ 是在从 $i$ 开始的 $m$ 个信号之间的局部单调信号的话，那么对于尺寸为 $N=2M+1 \ (M \leq m-2)$ 的中央值滤波器，这样的信号为这个滤波器的 root 信号。

几个典型的非线性滤波器

中央值滤波器 (Median Filter)

正如第一节所述，中央值滤波器可以有效去除椒盐噪声，并且不会使图像产生模糊。下面将一幅图像染上椒盐噪声，然后使用不同尺寸的中央值滤波器进行处理，所得结果的画质使用SSIM进行评价。

首先，将图像染上盐粒密度为0.15、胡椒密度为0.15的椒盐噪声，分别使用 $3 \times 3$、$5 \times 5$、$7 \times 7$ 和 $9 \times 9$ 四种尺寸的中值滤波器反复处理，SSIM随处理次数的变化如下图所示。

由图可见，滤波器尺寸不同，所得到的结果也不同，尺寸较大的滤波器反而得到了不太好的结果。随着循环次数的增加，图像的SSIM逐渐变化，最后趋于稳定。下图给出了循环次数为30时，四种尺寸滤波器所得到的图像。

为了考察噪声强度对实验结果的影响，将图像染上盐粒密度为0.35、胡椒密度为0.35的椒盐噪声，再进行同样的滤波实验，可以得到如下曲线。

在这一组实验中，$3 \times 3$ 滤波器的SSIM在前期上升明显缓慢，需要更多的处理次数才能收敛；而在噪声较强的条件下，$5 \times 5$ 滤波器反而取得了更好的结果。

综合上述实验，可以得到三个有用的结论：

  1. 中央值滤波器在处理过程中，不断地在寻找 root 信号。反复数次之后，其结果收敛，基本不再改变。
  2. 对于不同的图像、不同的噪声，最适合的中央值滤波器尺寸是不同的，并不是尺寸越小越好。
  3. 尺寸小的滤波器收敛速度慢；反之，尺寸大的滤波器收敛较快。

自适应中央值滤波器

要用好中央值滤波器，关键只有一点：找到一个最合适的滤波器尺寸，使得原图恰好就是这个滤波器的 root 信号，那么就可以得到一个完美的结果（当然，这样理想的滤波器是不存在的）。由此可以引出一个思路：在执行滤波操作时，尽可能多地尝试各种尺寸，从中选择一个最合适的，让原图尽量接近该尺寸滤波器的 root 信号，这样就能得到一个不错的结果。

此外，针对椒盐噪声还可以加入这样一个判断：由于噪声的灰度值是已知的（盐粒噪声为1，胡椒噪声为0），因此只有当中央值不为0或1时滤波器才生效，否则就扩大滤波器的尺寸。

               goto NEXT;

          else goto START;

最大值滤波器与最小值滤波器

最大值滤波器与最小值滤波器同中央值滤波器有些类似，同样是以寻找 root 信号为目的，只不过最大值滤波器可用于去除盐粒噪声，相反地，最小值滤波器则可用于去除胡椒噪声。同样地，这两种滤波器都不适用于去除同时含有盐粒噪声与胡椒噪声的图像。

由于原理比较简单，这里就不给出实验结果了。

中点滤波器 (Midpoint Filter)

中点滤波器糅合了均值滤波器与非线性的排序处理，其表达式如下。

\[\begin{aligned} \hat{f}(x,y) = \frac{1}{2} \left[ \max_{(s,t) \in S_{xy}} \lbrace g(s,t) \rbrace + \min_{(s,t) \in S_{xy}} \lbrace g(s,t) \rbrace \right] \end{aligned}\]

这样的滤波器对于去除高斯噪声与均匀噪声这类随机分布的噪声有较好的效果。下面将它与算术均值滤波器做一个比较，结果如下图所示。图中纵轴表示画质SSIM，横轴表示噪声的方差，绿线表示中点滤波器，红线表示算术均值滤波器。

修正的阿尔法均值滤波器

在唱歌比赛的评分中，评委打分时总是要去掉一个最高分、去掉一个最低分，然后再求均值，这样可以更好地反映一个选手的真实水平。在图像处理领域，也有一种与之类似的处理方法，其表达式如下。

\[\begin{aligned} \hat{f}(x,y) = \frac{1}{mn - 2d} \sum_{(s,t) \in S_{xy}} g_{r}(s,t) \end{aligned}\]

简单地理解一下这个滤波器：首先将滤波范围 $S_{xy}$ 内的 $mn$ 个数据进行排序，按从大到小的顺序去除 $d$ 个数据，再按从小到大的顺序去除 $d$ 个数据，将剩下的 $mn-2d$ 个数据计算均值，即为该点的输出。

这样的滤波器很擅长去除被椒盐噪声与其他类型噪声共同污染的图像。下面依然通过实验来验证：首先将图片染上盐粒密度为0.1、胡椒密度为0.1的椒盐噪声，然后再将这幅图像染上高斯噪声，最后进行去噪处理，所得结果如下图所示。

可以看出，对于这种复合的噪声，修正的阿尔法均值滤波器（紫线）的效果是最好的。另外值得注意的是，几何均值滤波器（红线）的SSIM几乎贴近于0，这正是上一篇博文中所提到的原因——图像中含有胡椒噪声，其0值使得几何均值滤波器完全失效。

%% ------------Adaptive median filter--------------------
close all;
clear all;
clc;

f = imread('./ckt-board-orig.tif');
f = mat2gray(f,[0 255]);
[M,N] = size(f);

% ----------------noise----------
b = 0.3;    %salt
a = 0.3;    %pepper
x = rand(M,N);
g_sp = f;
g_sp(find(x<=a)) = 0;
g_sp(find(x > a & x<(a+b))) = 1;

figure();
subplot(1,2,1);
imshow(g_sp,[0 1]);
xlabel('a).Image corrupted by S&P noise');

subplot(1,2,2);
x = linspace(-0.2,1.2,358);
h = hist(g_sp,x)/(M*N);
Histogram = zeros(358,1);
for y = 1:256
    Histogram = Histogram + h(:,y);
end
bar(-0.2:1/255:1.2,Histogram);
axis([-0.2 1.2 0 0.04]),grid;
xlabel('b).The Histogram of a');
ylabel('Number of pixels');

[SSIM_g mssim] = ssim_index(f,g_sp,[0.01 0.03],ones(8),1);

%% Adaptive median filter
S_xy = zeros(3,3);
z_min = 1;
z_max = 0;
z_med = 0;
S_max = 7;

w = zeros(S_max,S_max);
w(round(S_max/2),round(S_max/2)) = 1;
g_Ex = imfilter(g_sp,w,'symmetric','full');

g_Admf = zeros(M,N);
S = 3;
for x = 4:M+3
    for y = 4:N+3

        %  A
        for S = 3:2:S_max
            S_xy = zeros(S,S);
            for s = 1:1:S
                for t = 1:1:S
                    S_xy(s,t) = g_Ex(x+s-round(S/2),y+t-round(S/2));
                end
            end
            z_min = min(S_xy(:));
            z_max = max(S_xy(:));
            z_med = median(S_xy(:));

            A_1 = z_med - z_min;
            A_2 = z_med - z_max;

            if ((A_1>0)&&(A_2<0))
            % B
              B_1 = g_Ex(x,y) - z_min;
              B_2 = g_Ex(x,y) - z_max;
              if((B_1>0)&&(B_2<0)) g_Admf(x-3,y-3) = z_med;break;
              else g_Admf(x-3,y-3) = z_med; break;
              end
            end

            if(S >= S_max)  g_Admf(x-3,y-3) = z_med; break;
            end
        end

    end
end

figure();
subplot(1,2,1);
imshow(g_Admf,[0 1]);
xlabel('c).Ruselt of denoise by Adaptive median filter');

subplot(1,2,2);
x = linspace(-0.2,1.2,358);
h = hist(g_Admf,x)/(M*N);

总结

本文介绍了几种用于图像去噪的非线性滤波器。与均值类的线性滤波器不同，这类滤波器的目的并不是频率成分的选择，而是通过排序处理去逼近 root 信号，因此在去除椒盐噪声的同时不会使图像产生明显的模糊。

其中，中央值滤波器的效果取决于尺寸的选择，而自适应中央值滤波器通过动态调整尺寸，在强噪声条件下有着明显更好的表现；最大值与最小值滤波器分别适用于盐粒噪声与胡椒噪声；中点滤波器适用于高斯噪声与均匀噪声这类随机分布的噪声；修正的阿尔法均值滤波器则在多种噪声复合污染的场合表现最好。
