上一篇博文对噪声的类型进行了介绍，也使用的Matlab对各种噪声进行了实现。同时，上一篇博文的开头，也对图像退化过程进行了建模，即

这个退化模型可以用如下数学表达式来描述：

\[\begin{aligned} g(x,y) = h(x,y) \star f(x,y) + \eta (x,y) \end{aligned}\]

在这里，$f(x,y)$ 表示原图数据， $h(x,y)$ 表示退化滤波器，$\eta (x,y)$ 代表了加性噪声，$g(x,y)$ 则表示退化后的图像结果。

本文主要对噪声抑制（也就是消除 $\eta (x,y)$ ）的滤波器进行了简要介绍。至于退化函数 $h(x,y)$ 的去除（称为去卷积或者逆滤波），将放在之后的博文中讨论。

实验用图像

评价方式

实验的步骤为，将实验用图像加上加性噪声，然后使用滤波器进行去噪，比较所得到的图像的画质。这里，就涉及到画质的评价方法。一般的，去噪图像的评价一般使用PSNR（峰值信噪比）。

\[\begin{aligned} PSNR &= 10 * log_{10}{\frac{\sum_{i=0}^{M-1}\sum_{j=0}^{N-1} [2^n - 1]^2}{\sum_{i=0}^{M-1}\sum_{j=0}^{N-1} [g(x,y) - \stackrel{\sim}f(x,y)]^2}} \\ &= 10 * log_{10}{\frac{[2^n - 1]^2}{MSE}} \\ &= 10 * log_{10}{\frac{MAX^2}{MSE}} \\ \end{aligned}\]

对于8-bit的图片而言，这里的MAX为255。PSNR越大，其画质就越好。但是，有些时候，使用PSNR来进行评价，也有不太合理的时候。

比如是对原图进行了不同处理，得到三张不同的图像： a)是使用平均滤波器进行了处理，使其有些模糊 b)是使用高斯噪声污染原图 c)是使用椒盐噪声污染的图像。

—-原图a)b)c)
PSNR$ \inf $$ 23.238[dB] $$ 23.2328[dB] $$ 23.2325[dB] $

因为这三张图，其实是算法精心调整过的，三幅图像的PSNR基本是一样的。所以，如果使用 PSNR 作为指标，那么势必存在一些局限性。 实际上，PSNR计算的时候，使用了MSE这个量。而MSE仅仅表现了两幅图像的灰度值的差，而对于图像的结构，却没有进行任何分析。这里使用一种比较好的图像画质评价的方法：SSIM（念做：艾斯-希姆）。这是一种由两张图像的灰度差异，构造差异和对比度去判断两张图的接近程度的方法。详情请参考 📎  » The SSIM Index for Image Quality Assessment «  。

SSIM1从图像亮度(Luminance)，图像对比度(Contrast)和图像构造(Structure)去判断处理过的图像与原图的差异。这里，使用了某个区域的内的平均值作为亮度度量，使用方差作为对比度度量，使用协方差作为构造度量，来进行判断。

\[\begin{aligned} SSIM &= [l(x,y)]^{\alpha} * [c(x,y)]^{\beta} * [s(x,y)]^{\gamma} \\ l(x,y) &= \frac{2\mu_{x}\mu_{y} + C_{1}}{\mu_{x}^{2}\mu_{y}^{2} + C_{1}} \\ c(x,y) &= \frac{2\sigma_{x}\sigma_{y} + C_{2}}{\sigma_{x}^{2}\sigma_{y}^{2} + C_{2}} \\ s(x,y) &= \frac{\sigma_{xy} + C_{3}}{\sigma_{x}\sigma_{y} + C_{3}} \\ \end{aligned}\]

使用SSIM求取上面三幅图象的类似度。

从上表可以看出来，通过使用SSIM进行判断的结果，更加符合人眼的主观感受。本文余下的实验，全部使用SSIM去判断画质。

线性滤波器

本节讨论的几种滤波器，都属于均值类的线性处理。它们的共同点是，取当前像素邻域 $S_{xy}$ 内的像素值，按照某种平均的方式求取一个代表值，作为该点的输出。这里的 $S_{xy}$ 表示以 $(x,y)$ 为中心、尺寸为 $m \times n$ 的邻域，本文的实验均取 $3 \times 3$ 的邻域。

算术均值滤波器

算术均值滤波器是其中最简单的一种，即求取邻域内所有像素的算术平均值，可用下式表示。

\[\begin{aligned} \hat{f}(x,y) = \frac{1}{mn} \sum_{(s,t) \in S_{xy}} g(s,t) \end{aligned}\]

从式子的形式可以看出，这是一个典型的低通滤波器，在抑制噪声的同时，也会使画面产生模糊，其去噪能力是有限的。下面通过实验进行验证。

首先对实验用图像加噪，噪声类型为高斯噪声，均值为0、方差为0.0298。

接下来使用算术均值滤波器进行去噪，结果如下。

从结果来看，噪声确实被抑制了一部分，但改善程度相当有限。观察其频率域的图像（图c），可以清楚地看到高频成分被衰减，这也印证了前面的判断——算术均值滤波器本质上就是一个低通滤波器。

几何均值滤波器

几何均值滤波器求取的是邻域内像素的几何平均值，其表达式如下。

\[\begin{aligned} \hat{f}(x,y) = \left[ \prod_{(s,t) \in S_{xy}} g(s,t) \right]^{\frac{1}{mn}} \end{aligned}\]

《Digital Image Processing》2中指出，该滤波器的去噪效果与算术均值滤波器基本相当，但在处理过程中丢失的图像细节会更少一些。

同样对实验用图像加噪，噪声类型为高斯噪声，均值为0、方差为0.17。

由结果可见，其去噪效果同样不甚理想，但在芯片引脚等细节的保留上，确实比算术均值滤波器要好一些。

需要特别注意的是，几何均值滤波器存在一个结构性的缺陷：只要邻域内出现一个0值，整个连乘的结果就立即为0，该像素点的输出也随之被置为0。这意味着几何均值滤波器无法用于去除胡椒噪声。

算术均值滤波器与几何均值滤波器的比较

4. 噪声：椒盐噪声，胡椒密度0.1，盐粒密度0

实验4中几何均值滤波器的SSIM仅为0.0848，其原因正是前面提到的0值问题——图像中包含了大量胡椒噪声，使得该滤波器完全失效。

综合这四组实验可以得出结论：算术均值滤波器的泛用性较好，对各类噪声都能取得较为稳定的效果；而几何均值滤波器则擅长于去除盐粒噪声，在实验3中它的表现甚至优于算术均值滤波器，但一旦遇到胡椒噪声就会失效。

由此可以引申出一个思路：既然几何均值滤波器擅长处理盐粒噪声，那么对于仅含胡椒噪声的图像，可以先将其取反，把胡椒噪声转换为盐粒噪声后再进行滤波，最后将结果取反还原。通过这种方式，几何均值滤波器同样可以用于去除胡椒噪声。

谐波均值滤波器

谐波均值滤波器的表达式如下所示。

\[\begin{aligned} \hat{f}(x,y) = \frac{mn}{\sum_{(s,t) \in S_{xy}} \frac{1}{g(s,t)}} \end{aligned}\]

注意式子的分母部分，由于对像素值取了倒数，该滤波器不但无法去除椒盐噪声，在处理灰度过低的图像时同样会出现问题。《Digital Image Processing》2中指出，这种滤波器擅长于处理高斯噪声，下面通过实验进行验证。

对实验用图加噪，噪声类型为高斯噪声，均值为0、方差为0.15，各滤波器的处理结果如下。

—-加噪图像算术均值滤波器几何均值滤波器谐波均值滤波器
SSIM0.46350.72760.69460.6748

从实验数据看，在这一场景下谐波均值滤波器的去噪效果（0.6748）反而不如算术均值滤波器（0.7276）与几何均值滤波器（0.6946）。

逆谐波均值滤波器

逆谐波均值滤波器可以适应多种类型的噪声，其表达式如下。

\[\begin{aligned} \hat{f}(x,y) = \frac{\sum_{(s,t) \in S_{xy}} g(s,t)^{Q+1}}{\sum_{(s,t) \in S_{xy}} g(s,t)^{Q}} \end{aligned}\]

该滤波器可以通过调整 $Q$ 值来获得不同的滤波特性：当 $Q$ 为正时，可以去除胡椒噪声；当 $Q$ 为负时，则可以去除盐粒噪声。实验结果如下。

上排为盐粒噪声的处理结果，$Q=-1.5$ 时噪声被有效去除，而 $Q=1.5$ 时则几乎没有效果；下排为胡椒噪声的处理结果，两者的表现恰好相反。这与前面所述的 $Q$ 值特性是一致的。

        g_hmf(x-1,y-1) = g_hmf(x-1,y-1) +  1/g_Ex(x-1,y);
        g_hmf(x-1,y-1) = g_hmf(x-1,y-1) +  1/g_Ex(x  ,y-1);
        g_hmf(x-1,y-1) = g_hmf(x-1,y-1) +  1/g_Ex(x+1,y);
        g_hmf(x-1,y-1) = g_hmf(x-1,y-1) +  1/g_Ex(  x,y+1);
        g_hmf(x-1,y-1) = g_hmf(x-1,y-1) +  1/g_Ex(x-1,y+1);
        g_hmf(x-1,y-1) = g_hmf(x-1,y-1) +  1/g_Ex(x+1,y-1);
        g_hmf(x-1,y-1) = g_hmf(x-1,y-1) +  1/g_Ex(x+1,y+1);
        g_hmf(x-1,y-1) = g_hmf(x-1,y-1) +  1/g_Ex(x-1,y-1);

        g_hmf(x-1,y-1) = 9/g_hmf(x-1,y-1);
    end
end

g_hmf_diff = abs(g_hmf - f);
MSE_hmf = sum(sum(g_hmf_diff .^2))/(M*N);
PSNR_hmf = 10*log10((1*1)/MSE_hmf)

figure();
subplot(1,2,1);
imshow(g_sp,[0 1]);
xlabel('a).Image corrupted by pepper noise');

subplot(1,2,2);
imshow(g_hmf,[0 1]);
xlabel('b).Ruselt of Denoise by Hmf');

% Contraharmonic mean filter
Q = -1.5;

g_cmf = zeros(M,N);
for x = 2:M+1
    for y = 2:N+1
        g_cmf_M = (g_Ex(x  ,y))^(1+Q);
        g_cmf_M = g_cmf_M +  (g_Ex(x-1,y))^(1+Q);
        g_cmf_M = g_cmf_M +  (g_Ex(x  ,y-1))^(1+Q);
        g_cmf_M = g_cmf_M +  (g_Ex(x+1,y))^(1+Q);
        g_cmf_M = g_cmf_M +  (g_Ex(  x,y+1))^(1+Q);
        g_cmf_M = g_cmf_M +  (g_Ex(x-1,y+1))^(1+Q);
        g_cmf_M = g_cmf_M +  (g_Ex(x+1,y-1))^(1+Q);
        g_cmf_M = g_cmf_M +  (g_Ex(x+1,y+1))^(1+Q);
        g_cmf_M = g_cmf_M +  (g_Ex(x-1,y-1))^(1+Q);

        g_cmf_D = (g_Ex(x  ,y))^(Q);
        g_cmf_D = g_cmf_D +  (g_Ex(x-1,y))^(Q);
        g_cmf_D = g_cmf_D +  (g_Ex(x  ,y-1))^(Q);
        g_cmf_D = g_cmf_D +  (g_Ex(x+1,y))^(Q);
        g_cmf_D = g_cmf_D +  (g_Ex(  x,y+1))^(Q);
        g_cmf_D = g_cmf_D +  (g_Ex(x-1,y+1))^(Q);
        g_cmf_D = g_cmf_D +  (g_Ex(x+1,y-1))^(Q);
        g_cmf_D = g_cmf_D +  (g_Ex(x+1,y+1))^(Q);
        g_cmf_D = g_cmf_D +  (g_Ex(x-1,y-1))^(Q);

        g_cmf(x-1,y-1) = g_cmf_M/g_cmf_D;
    end
end

g_cmf_diff = abs(g_cmf - f);
MSE_cmf = sum(sum(g_cmf_diff .^2))/(M*N);
PSNR_cmf = 10*log10((1*1)/MSE_cmf)

figure();
subplot(1,2,1);
imshow(g_cmf,[0 1]);
xlabel('b).Ruselt of Denoise by Cmf(Q=-1.5)');

总结

本文介绍了几种用于图像去噪的均值类线性滤波器，并通过实验对它们的性能进行了比较。从实验结果来看，各种滤波器都有其各自适合的噪声类型：算术均值滤波器的泛用性最好；几何均值滤波器在保留细节与去除盐粒噪声上有优势，但会被胡椒噪声破坏；谐波均值滤波器适用于高斯噪声，却无法应对椒盐噪声；逆谐波均值滤波器则可以通过 $Q$ 值的选择来分别应对盐粒噪声与胡椒噪声。

需要指出的是，线性滤波器在抑制噪声的同时，不可避免地会带来图像的模糊。关于非线性滤波器的讨论，将放在下一篇博文中进行。
